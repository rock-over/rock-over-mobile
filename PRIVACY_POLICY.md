# 🔒 Rock Over - Política de Privacidade

**Última atualização:** Janeiro 2025

## 📱 Sobre o Rock Over

O **Rock Over** é um aplicativo mobile para escaladores registrarem e acompanharem suas sessões de escalada. Desenvolvido com React Native e Supabase, o app oferece uma experiência segura e personalizada para a comunidade de climbing.

## 📋 Informações que Coletamos

### 🔐 Dados de Autenticação
- **Email** e **nome** (para criação de conta)
- **Foto de perfil** (opcional)
- **ID do Facebook/Google** (quando usar login social)
- **Token de acesso** (temporário, para autenticação)

### 🧗 Dados de Escalada
- **Sessões de climbing** (data, local, rotas completadas)
- **Fotos das sessões** (opcional)
- **Sistema de graduação** preferido (V-Scale, YDS, etc.)
- **Localização das sessões** (quando fornecida)

### 📱 Dados Técnicos
- **Informações do dispositivo** (modelo, OS)
- **Logs de erro** (para melhorar a experiência)
- **Dados de uso** (features utilizadas)

## 🎯 Como Usamos suas Informações

### ✅ Finalidades Principais
- **Autenticação** e gerenciamento de conta
- **Armazenamento** de sessões de escalada
- **Personalização** da experiência do usuário
- **Backup** e sincronização entre dispositivos

### ✅ Finalidades Secundárias
- **Análise de uso** para melhorias no app
- **Suporte técnico** quando solicitado
- **Comunicação** sobre atualizações importantes

### ❌ O que NÃO fazemos
- **Não vendemos** seus dados para terceiros
- **Não enviamos** spam ou marketing não solicitado
- **Não compartilhamos** dados com outras empresas
- **Não usamos** dados para publicidade externa

## 🔗 Compartilhamento de Dados

### 🤝 Parceiros de Serviço
- **Supabase** (banco de dados e autenticação)
- **Google/Facebook** (apenas para login social)
- **Expo/React Native** (framework de desenvolvimento)

### 🛡️ Proteção Legal
Podemos compartilhar dados apenas quando:
- **Exigido por lei** (ordem judicial)
- **Proteção de direitos** (casos de fraude)
- **Emergências** (situações de risco)

## 🔐 Segurança dos Dados

### 🛡️ Medidas de Proteção
- **Criptografia** de dados sensíveis
- **HTTPS** em todas as comunicações
- **Autenticação segura** via OAuth2
- **Backup regular** com proteção

### 🔒 Armazenamento
- **Servidores seguros** (Supabase/AWS)
- **Acesso restrito** (apenas desenvolvedores autorizados)
- **Monitoramento** de segurança 24/7

## ⏰ Retenção de Dados

### 📅 Tempo de Armazenamento
- **Dados ativos:** Enquanto a conta existir
- **Dados de backup:** Até 90 dias após exclusão
- **Logs técnicos:** Até 12 meses
- **Dados anonimizados:** Podem ser mantidos para estatísticas

## 🌍 Seus Direitos (LGPD/GDPR)

### ✅ Direitos Garantidos
- **📄 Acesso:** Saber quais dados temos sobre você
- **✏️ Correção:** Corrigir dados incorretos
- **🗑️ Exclusão:** Deletar sua conta e dados
- **📦 Portabilidade:** Exportar seus dados
- **🚫 Oposição:** Revogar consentimentos
- **⏸️ Limitação:** Restringir processamento

### ⚖️ Base Legal
- **Consentimento:** Para dados opcionais (fotos, localização)
- **Execução contratual:** Para funcionalidades básicas
- **Interesse legítimo:** Para melhorias e suporte

1. **Recebimento:** Confirmaremos em até 2 dias úteis
2. **Verificação:** Validaremos sua identidade
3. **Exclusão:** Processamento em até 30 dias úteis
4. **Confirmação:** Notificaremos quando concluído

### 🗂️ Dados que Serão Excluídos
- ✅ Conta e credenciais de acesso

- ✅ Preferências e configurações
